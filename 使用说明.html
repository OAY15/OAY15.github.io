Rigframe 使用手册

把分层图变成会动的手书动画：摆位置、打关键帧、卡上音乐、导出视频。

v2 版本重点 - 每个属性（位置、旋转、缩放、透明度、贴图…）一条独立动画轨道，互不干扰 - 撤销时会告诉你撤销掉的是什么 - 钢琴窗只有一个：导入 MIDI、按卡点映射都会直接变成可编辑的音符

第一部分 · 基础

打开与界面

双击 index.v2.html，用 Chrome 或 Edge 打开。

第一次打开会看到中间的「载入示例角色」按钮。点它，会载入一套 11 个部件的角色，父子级已经连好，可以直接在上面练手。

界面分四块：

区域作用
左侧图层列表，控制父子级、显示、锁定
中间画布，摆部件、拖手柄
右侧属性 / 曲线 / 动作 / 场景四个标签页
底部工具栏 + MIDI 栏 + 钢琴窗 + 时间轴

导入角色

在自己的绘图软件里把角色拆成部件，每个部件导出一张 PNG，所有图层用同一个画布尺寸导出（不要各自裁剪），这样导进来能自动对齐。

文件名决定部件类型：

文件名包含识别为
head 头 face hair eye mouth头部部件
arm hand 手手臂
leg foot 脚腿
其他身体

同一部位的多张贴图用变体区分：mouth_closed.png、mouth_open.png 会合并成一个图层下的多张贴图。

导入方式：把文件拖进窗口，或点左上角「导入分层」。

摆位置与层级

  • 拖部件：在画布上按住拖动
  • 四角圆点：缩放
  • 旋转手柄：旋转
  • 滚轮：缩放画布（不是缩放部件）
  • 中键拖动 / 空格+拖动：平移画布

父子级：在左侧列表里把子层拖到父层上（按住 Alt 拖）。挂上之后：

  • 父层移动、旋转、缩放，子层跟着走
  • 子层自己的动画不会反过来拽动父层
  • 子层的位置存的是相对父层的局部坐标，父层怎么动都不会让子层脱节

典型结构：身体 → 头 → 眼睛 / 嘴 / 头发 / 皇冠。

换父级时位置不会跳：绑定、解绑都会把该图层的当前位置、静态值、x/y 关键帧、片段基准一起换算到新的父级坐标系，所以做过的位移动画不会因为换绑而错位。

如果你有旧版本留下的工程，某个子层一打开就跑到右下角，选中它，在属性面板「父级」右边点 ⟲ 就能把它的位置数据换算回父级坐标系。这个按钮只在有父级时出现，可以撤销。

图层资料夹

图层多了以后，列表会变得很长。资料夹只是归类，不影响动画和渲染顺序。

操作做法
新建资料夹左侧「图层 / 父子级 / 素材」那行的最右边点 ＋
把图层放进去把图层行拖到资料夹行上，或在属性面板的「资料夹」下拉里选
拿出来属性面板「资料夹」选「（不放入资料夹）」
折叠 / 展开点资料夹行，或点左边的三角
改名双击资料夹名字
删除资料夹点右侧 ×，里面的图层会回到列表，不会被删

资料夹会跟着工程保存。左侧计数显示的是图层总数，资料夹里的小数字是它装了几层。

资料夹只作用于左侧列表。时间轴仍然按图层平铺，不会按资料夹分组。

打第一个关键帧

  1. 把播放头放在第 0 拍
  2. 选中一个图层，摆好位置
  3. 点工具栏的「关键帧」按钮，或在属性面板「动画轨道」里点属性名
  4. 把播放头移到第 2 拍，把图层挪到新位置
  5. 播放 —— 它动了

自动记录（工具栏那个红点开关）打开时，你每次改动都会在当前帧自动打点。第一次摆位置时建议关掉，否则会留下一堆位置关键帧。

v2 起，打点是按属性的：改 X 就只给 X 打点，不会顺带把旋转、嘴型也记一份。

加音乐与卡点

导入音乐：工具栏「导入音乐」，或直接把音频拖进窗口。

卡点：播放时按 T，或点工具栏「卡点」。卡点是时间轴顶部的三角标记，用来对齐重音。

对齐音乐：音乐在时间轴上是一条可以拖的片段——按住它左右拖就是移动，拖两端就是裁剪。差一点点就微调一下，不用重新导入。

导出视频

点右上角「导出视频」：

选项说明
帧率24 / 30 / 60
尺寸画布的 100% / 75% / 50%
格式MP4（需要 ffmpeg）或 WebM
范围默认整段，可以只导一段

导出会逐帧渲染，导出期间别切走标签页。

自动保存与崩溃恢复

编辑器每 60 秒把当前工程打包一份快照，只在有改动时才写。

情况结果
改了东西没保存一分钟后自动落一份快照
正常保存了快照立刻删除，不会再提示
崩溃 / 直接关掉快照留着，下次打开会问你要不要恢复
打开另一个工程上一份快照作废

标题栏前面有 • 就表示当前有改动还没保存。

桌面版的快照写在用户数据目录（便携模式在 data/autosave/），不限大小； 网页版退化成浏览器存储，超过 2.4MB 的工程会自动跳过。

恢复提示出现在两个地方：

  • 桌面版启动器左侧的「发现未保存的工程」卡片，显示图层数和时间
  • 直接打开编辑器时，中间的弹窗

恢复之后建议马上「另存为」存到磁盘——快照只有一份，会被下一次自动保存覆盖。

第二部分 · 进阶

属性轨道

这是 v2 最大的变化。 一个图层不再是一串「完整快照」，而是每个属性一条独立轨道：

图层 mouth
├─ X 位置   ●──●────────●
├─ Y 位置   ●────────────
├─ 旋转     ──────●──────
├─ 缩放X    （空）
├─ 缩放Y    （空）
├─ 透明度   ●──────●
├─ 色相     （空）
├─ 贴图     ●─●─●─●─●─●
├─ 水平镜像 （空）
└─ 垂直镜像 （空）

为什么重要：

  • 给旋转打点做转头，同时给贴图打点做对口型，两者完全独立
  • 挪整体位置（X/Y）不会破坏已经做好的嘴型切换
  • 删除某个属性的关键帧，不会连带删掉别的属性

怎么用

属性面板顶部有一个「动画轨道」区，10 个按钮对应 10 条轨道：

  • 灰点 = 这条轨道还没有关键帧
  • 蓝点 + 数字 = 已有几个关键帧
  • 高亮 = 播放头正好落在这条轨道的某个关键帧上

点一下按钮：在播放头打一个关键帧。 再点一下：删掉播放头处的那个关键帧。

拖动滑块、改数字框时，只有那个属性会打点（自动记录开着的前提下）。

撤销会告诉你是谁

Ctrl + Z 之后底部会显示「撤销：调整旋转」这样的提示，不再是盲撤。

子轨道模式（不可逆）

如果这个图层的动画要精细到「每个属性各管各的」，可以点工具栏的「子轨道」按钮（属性面板底部也有一个）。

开启后当前正在编辑的那条子轨道会整行淡高亮，一眼能看出在改哪条。

开启后：

  • 时间轴主行不再显示总关键帧，只显示动作片段
  • 只有 10 条属性子轨道上的点，每个点都是独立关键帧
  • 每个点可以单独选中、拖动、删除、调曲线、存为组件
  • 属性面板的计数变成「轨道关键帧（N）」，N 是所有轨道点数之和

⚠️ 不可撤销。开启前会二次确认，开启后连撤销也退不回去。建议先保存工程。

拖到重叠位置会推挤

把一个关键帧拖到已有另一个关键帧的位置时，被撞的点会往后让一个 1/4 拍，而不是被覆盖掉。

连续撞多个就依次往后排，形成 0.25 拍间隔的队列，不会丢任何关键帧。拖到 0 左侧时会自动反弹向右推。

钢琴窗与贴图轨

钢琴窗只有一个，它编辑的是当前选中图层的贴图轨：一个音符 = 那段时间显示这张贴图。

三种铺音符的方式

方式操作
手画在格子里按住拖，拖多长就停多久
按卡点铺打好卡点 → 点「按卡点映射」→ 自动生成音符
按 MIDI 铺导入 MIDI → 点「按 MIDI 映射」→ 按音符时间生成

导入 MIDI 只取时值：起点和时长照搬，音高不参与。贴图按顺序循环切换（1→2→3→…→回到 1），默认贴图留作音符之间的空档。所以一段旋律会自动变成"嘴一张一合"。

MIDI 文件里带的速度会自动写进 BPM，不用手动对；想改回去直接改工具栏的 BPM。

三种方式生成的音符都能再改：拖位置、拖右边缘改时长、右键删除、Shift+拖框选。

实时烘焙

每次改动音符，贴图关键帧立刻重新烘焙，不用等播放，也不用点「生成」。

静音贴图

音符之间的空档显示哪张。下拉第一项是「无（保持当前）」——选了它，音符结束后不回切，那张图一直保持到下一个音符。

动作片段与组件

动作片段：把一段关键帧打包成方块，在时间轴上可以拉伸、复制、循环。右键片段可以「分解为关键帧」还原。

组件：把一段动作存进库，下次可以直接套到别的图层。

单属性组件：如果只想把某一条属性的动画存起来（比如「只转头的旋转曲线」），在时间轴上选中同一条子轨道的两个以上关键帧，再点「存为组件」。这样存出来的组件只含那一条属性，套到别的图层时只影响那条属性，不会碰位置、缩放、贴图。

多组件叠加：一个图层可以同时挂多个组件。只含旋转的组件和只含贴图的组件叠在一起，各管各的属性，互不覆盖。

存组件时选「相对」，套用时就会以目标图层当前位置为基准。

组件存在哪里

组件跟着工程走，存在工程文件里，不再只留在当前浏览器。

动作结果
存为组件进「我的组件」列表，等保存工程时写进 .rfz
保存工程组件库一起打包，换电脑打开也在
打开工程组件库换成那个工程自带的
新建工程组件库清空（和图层、片段一致）
撤销删除组件Ctrl + Z 可以把刚删的组件找回来

旧版本存在浏览器里的组件，第一次启动时会自动并入当前会话，并提示数量；保存一次工程后它们就跟着工程走了。

这也意味着：组件不会跨工程自动共享。想让两个工程都用同一个组件，把带组件的那份工程另存一份再改，或者在另一个工程里重新存一次。

蒙版与形变

蒙版：用另一个图层的透明度裁剪这一层。属性面板 →「蒙版」→ 选裁剪源。眼皮裁眼白、头发裁脸、遮罩转场都用它。

发丝摆动：挂在父级下的图层可以开摆动，父级一动它就跟着甩。参数在属性面板「发丝摆动」里。

网格形变：高级用法，可以对贴图做弯折。形变数据跟着关键帧走。

音频分析

「场景」标签的音频区有三个工具：

自动检测 BPM

分析音乐重拍间隔，估算速度并四舍五入写进 BPM。快歌可能算出半拍或双拍，不对就手动填一半或两倍。

人声 → MIDI

按能量切出音节，生成 MIDI 音符，再点「按 MIDI 映射」就能让贴图跟着人声切。

局限：没有做声源分离。伴奏鼓点也可能被当成音节。想要干净结果，先用别的工具把人声单独导出来。

音频片段

音乐在时间轴上是一条独立轨道，和动作片段一样可以搬、可以裁。

操作做法
移动在音频轨上按住片段左右拖
裁剪左端拖片段左边的手柄（改的是入点，音频内容不跑）
裁剪右端拖片段右边的手柄（改的是出点）
精确设置「场景」标签里填「起点」（拍）、「入点 / 出点」（秒）
对齐播放头点「对齐播放头」，片段起点落到当前播放头
恢复完整点「恢复完整」，清掉裁剪

入点 / 出点是源文件里的秒数，不是时间轴上的位置。裁掉的部分不参与播放，也不参与导出——导出视频时只输出片段范围内的音频。

起点可以是负数（音乐比第 0 拍更早开始），这种情况下第 0 拍听到的是音乐中间某处。

播放头在片段外面时画面照常推进，只是没声音；走进片段范围会自动接上声音，走过出点自动停声。

素材库与图形

左侧第三个分页「素材」里放着内置图形。点一下就在画布中央插入一个图形图层，随后在右侧「图形」里调参数。

12 种形状

三角形、正方形、圆形、星形、多边形、菱形、圆角矩形、环形、箭头、十字、对话气泡、横条。

可调参数

参数说明
形状随时换种类，尺寸和颜色保留
尺寸宽 × 高，改完按回车。改尺寸时图形绕中心缩放，不会跑位
填充勾选＝实心；取消勾选＝中空（只留描边）
填充色 / 描边色点色块选颜色
描边开关 + 宽度（0–200）
角数 / 内径仅星形：几个角、内圈半径百分比（越小越尖）
边数仅多边形
圆角仅圆角矩形 / 对话气泡
环厚仅环形，环的粗细百分比

中空又没描边会看不见，所以取消填充时如果描边是关的，会自动帮你打开描边。

图形是矢量的

图形存的是参数 + 一段 SVG，不是位图。所以放大到 4 倍依然锐利，工程文件也几乎不增大。

图形图层和普通图层完全一样：能移动、旋转、打关键帧、设父子、进资料夹、套组件、加蒙版、参与导出。改完形状参数后已经打好的关键帧不受影响。

连续插多个

插入时会记住上一次用过的填充色、描边色和线宽，连续做同一套风格的图形不用反复调。

文字图层

文字是一等图层，能变换、打关键帧、设父子、加蒙版、参与导出。

左侧面板底部「＋ 文字」新建。属性面板的「文字」区可以改：内容、字体、字号、字重、颜色、对齐、行距、斜体、描边、阴影。

字体：35 种，全部免费可商用（思源黑体/宋体、霞鹜文楷、站酷系列、马善政、龙藏、Inter、Roboto、Bebas Neue…）。第一次选某个字体才联网加载，加载完自动重绘。

文字图层没有贴图，所以「贴图」「按卡点映射」相关按钮会对它禁用。

常见问题

Q：导入后部件全叠在一起

贴图导出时没有用统一画布尺寸。重新导出，所有图层保持同样的画布大小。

Q：拖不动图层

看左侧列表的锁图标是不是锁上了。

Q：改了位置，嘴型对不上了

v2 不会出现这个问题——位置和贴图是两条独立轨道。如果还在旧版本，升级到 v2。

Q：按了关键帧但没反应

检查自动记录是否关闭、播放头是否停在同一个时间点（同一帧是覆盖打点）。

Q：导出很慢 / 卡住

导出是逐帧渲染，长视频会慢。可以先导 50% 尺寸试效果。

Q：字体没变

Q：钢琴窗里没有音符

先确认左侧选中了图层，且该图层有 2 张以上贴图。

已知限制

  1. 只能导出 WebM / MP4，没有 GIF
  2. 没有参考视频叠底，不能对着原片描
  3. 组件不跨工程共享，各自存在工程文件里（同一工程换设备打开没问题）
  4. MIDI 不重建速度曲线，只按拍对齐
  5. 人声分析不做声源分离，伴奏会混进来
  6. 裁切是破坏性的，裁完不能扩回去（撤销除外）
  7. 字体第一次用要联网
  8. 文字不支持富文本，一个图层只能一种样式
